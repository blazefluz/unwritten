# Synthetic workflow preview

`synthetic-workflow.html` and `synthetic-workflow.json` demonstrate the general
workflow notebook using the scripted fixtures in `tests/test_workflow.py`.
They are **synthetic test data, not real video observations or model output**.
The reference is invented for the test and is not a manufacturer manual or an
operating procedure. No measured accuracy is claimed.

Open the HTML file locally to inspect observed actions, hypotheses, model
assessments, verbatim citations and the expert question. Run `unwritten analyze`
on a rights-cleared video and applicable reference excerpts for a real run.
