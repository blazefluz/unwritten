# Three-minute demo draft

This is a script outline. Replace bracketed fields with measured results. No
accuracy, real run, or expert-answer feature is claimed complete here.

| Time | Screen and narration |
|---|---|
| 0:00–0:15 | State what was built during the hackathon and identify third-party SDKs and footage. “Unwritten learns the rules people follow without writing them down.” |
| 0:15–0:35 | Show the sorting task and explain the practical training/documentation problem. Identify staged footage or licensed footage explicitly. |
| 0:35–1:00 | Show Muse Spark's observation log beside the source video. Point to one item, its attributes and its destination. Acknowledge an actual observation uncertainty. |
| 1:00–1:30 | Show a proposed ordered rule, the deterministic checker and a real counterexample. Show an actual revision if one occurred. Do not manufacture a failure to create a story. |
| 1:30–2:05 | Play a held-out item: show its rule prediction before revealing placement. Explain that playback uses a previously analysed video; it is not live perception. |
| 2:05–2:30 | Show human-reviewed event counts, observation accuracy, held-out prediction accuracy and the OneR comparison. Explain sample size and any limitations. |
| 2:30–2:50 | Show a targeted question caused by missing coverage. Until interactive answers are implemented, describe it as a question for the expert, not an automatic update. |
| 2:50–3:00 | Show the public repository, reproducible setup and footage credits. End with the next practical validation step. |

Record only implemented features. Keep secrets, billing details and personal data
out of the recording. Verify the final video is at most three minutes and its
link can be opened by judges.
